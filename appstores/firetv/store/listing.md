# Store listing: pwamart (Fire TV)

- **Title:** pwamart
- **Package:** com.pwamart.tv
- **Category:** Utilities (app discovery / directory)
- **Price:** Free. No in-app purchases in the Fire TV app. No ads.
- **Content:** a catalog of Progressive Web Apps (web apps) published by their own
  authors. pwamart does not host or install Android apps; everything it lists opens
  in the browser.
- **Audience:** 13+
- **Collects data:** nothing in the Fire TV app itself. Signing in (optional, and only
  for people who publish apps) uses an email address on pwamart.com.
- **Privacy policy URL:** https://profullstack.com/privacy
- **Support:** anthony@profullstack.com, https://github.com/profullstack/pwamart.com/issues

## Short description

Browse and search pwamart, the app store for Progressive Web Apps, on your TV.

## Long description

pwamart is the app store for Progressive Web Apps: web apps that install on any phone, tablet or computer without a native app store. This is pwamart on the big screen, driven entirely by the remote.

- Search thousands of listed web apps by name or what they do
- Browse by category and by curated collections built for a workflow
- Open any listing to see what the app does, who publishes it, and the surfaces it offers (web, CLI, API, MCP)
- Remote-first: the D-pad moves a clear focus ring, OK opens, Back walks back, and the Menu key opens search from anywhere
- Free, open source (MIT): github.com/profullstack/pwamart.com

pwamart lists Progressive Web Apps published by their authors. It does not install or distribute Android apps.
